# Clean MIUI AI — Claude Code / Universal AI Guide

This repository provides a safe, reversible, non-root workflow to clean ads/bloatware and polish the UI on Android / Xiaomi (MIUI & HyperOS) phones without flashing ROMs or changing the OS.

- **Mandatory Rules:** Follow [`AGENTS.md`](AGENTS.md).
- **Step-by-Step Playbook:** Follow [`skills/clean-miui-ai/SKILL.md`](skills/clean-miui-ai/SKILL.md) in strict order: Connect -> Backup + Dry-Run Restore Verify -> Analyze & Propose -> Explicit Approval -> Apply -> Verify -> UI Guide.
- **Setup & UI Docs:** Refer to [`docs/CONNECTION_GUIDE.md`](docs/CONNECTION_GUIDE.md) and [`docs/UI_AND_CONTROL_CENTER_GUIDE.md`](docs/UI_AND_CONTROL_CENTER_GUIDE.md).
