# Clean MIUI AI — Gemini / Antigravity Project Guide

This repository provides a safe, reversible, non-root workflow to clean ads/bloatware and apply a clean stock-style UI on Android / Xiaomi (MIUI & HyperOS) phones using the existing OS.

- **Workspace Rules:** Follow [`AGENTS.md`](AGENTS.md) strictly.
- **Full AI Execution Workflow:** Read and follow [`skills/clean-miui-ai/SKILL.md`](skills/clean-miui-ai/SKILL.md) end-to-end.
- **Device Connection Help:** Direct users needing USB or same-Wi-Fi Wireless setup to [`docs/CONNECTION_GUIDE.md`](docs/CONNECTION_GUIDE.md).
- **UI & Control Center Polish:** Use [`docs/UI_AND_CONTROL_CENTER_GUIDE.md`](docs/UI_AND_CONTROL_CENTER_GUIDE.md) for layout, density (`440 dpi` / `392dp` fix), Control Center, and manual ad toggles.
